# Subtitle Translator Overlay 0.2.2

Changes completed on September 8, 2026.

## A simpler interface

- Rebuilt the main window around two actions: continuous subtitle translation and one-shot **Translate an area**.
- Removed the separate Focus mode and Game mode switches.
- Removed the shortcut hint from the main screen. Configure shortcuts in **Settings → Translation**.
- Show the bottom translation status only when developer mode is enabled. Actionable errors remain visible.
- Prioritized translated text, with an expandable English original and scrollable long results.
- Added minimize/quit controls and remembered window size.

## Appearance and settings

- Ship exactly two themes: **Dark** and **Light**. Removed the old colored and Nothing theme styles; existing choices migrate to a supported theme.
- Keep the interface entirely in English, with a separate message catalog and fallback mechanism for future interface languages.
- Added a shared, validated theme registry so future themes do not need per-window layout changes. A custom-theme editor is not included.
- Organized settings into Translation, Display, Appearance, Dictionary and Advanced, with an overlay preview.
- Record shortcuts by pressing the desired keys, detect conflicts, and retain the previous shortcut if saving fails.
- Reset settings in one persistence transaction while keeping the dictionary and subtitle area.

## Capture, editing and dictionary

- Pause continuous subtitles during one-shot capture. Cancellation restores the previous session; successful results stay until subtitles are explicitly resumed.
- Preserve original text when editing is cancelled and prevent late translation responses from replacing newer results.
- Keep the full result in the main window when subtitles are displayed over video.
- Pause updates while text is selected for the dictionary.
- Improve dictionary pagination, export errors and keyboard navigation in dialogs.
- Replace misleading Easy/Hard review choices with a single review pass, progress and completion.

## OCR and reliability

- Improve subtitle image preparation by retaining aligned glyphs and punctuation, rejecting unrelated background blobs, adding borders and normalizing letter height.
- Cover noisy backgrounds, yellow subtitles and two-line captions with synthetic fixtures.
- Harden OCR worker lifecycle, stale-result handling, translation recovery and serialized settings/dictionary persistence.
- Package OCR worker dependencies and the local English model explicitly.
- Refresh architecture, development workflow and verification documentation.

## Download and validation

Download **Subtitle-Translator-Overlay-0.2.2.exe** below. It is a portable Windows x64 application; no installation is required. Close an older instance before launching this build.

Automated verification covers unit tests with coverage thresholds, real Electron rendering, UI contracts, offline OCR and packaged OCR resources. These checks do not replace testing on real video/game content and physical Windows DPI configurations. The application remains oriented around the primary display, OCR quality depends on the source, and translation requires internet access.
