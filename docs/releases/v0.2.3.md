# v0.2.3

## Changes

- Added English, Russian, Simplified Chinese, Hindi and Spanish interface languages. English is the default interface language.
- Added translation target selection. Changing the interface language also changes the translation target; it can then be adjusted independently. English displays the original OCR text.
- Prevented cached or pending translations from the previous language appearing after a language switch. Dictionary entries retain their target language.
- Replaced title-bar text buttons with a menu icon and settings gear, and added an application icon.
- Bundled the official English `tessdata_fast` OCR model with pinned source provenance.
- Added third-party license documents, model integrity checks and license files to Windows release assets.

## Validation

251 automated tests passed, together with Electron UI, source OCR, syntax and packaged OCR checks. Translation requests for Chinese, Hindi and Spanish were checked against the service. Live gameplay and physical multi-monitor/DPI behavior still require manual testing.

## Download

Run `Subtitle-Translator-Overlay-0.2.3.exe` on Windows. No Node.js installation or separate OCR model download is required. OCR recognizes English; translation and dictionary context requests require network access. The executable is unsigned.

License documents are included in the application and attached to the release. `SHA256SUMS.txt` contains checksums for the downloadable executable and license files.
